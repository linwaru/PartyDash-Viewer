# Security Policy

## Supported versions

This project currently supports the `main` branch. Security fixes are applied to the latest state of the project.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue or pull request.

Use GitHub's private vulnerability reporting feature for this repository:
https://github.com/linwaru/PartyDash-Viewer/security/advisories/new

Please include a clear description, reproduction steps, and the potential impact. Reports will be reviewed as soon as practical. Please avoid including secrets or personal information in the report.

## Scope

This policy covers the code and configuration maintained in this repository. Third-party services, modified game files, and vulnerabilities in dependencies should be reported to their respective maintainers when appropriate.
